# WEB-02 自力課題の仕様

状態: 採点対象の問題文ではありません。教員用の初版仕様。具体的な別file、初期状態、採点条件はLab環境の検証後に確定します。

## 学生に求める行動

練習で使わなかった静的ファイルを教員が配布します。学生は要求されたpathでその内容をHTTPで取得できるようにし、file、service、port、client response、access logの関係を説明します。Ubuntu自身からの確認と、教員が指定する別clientからの確認を区別します。

## 自力課題の到達証拠

- 指定したURLから、指定した内容とstatus 200が返る。
- 対象serviceがactiveであり、想定したportで待ち受けている。
- 該当requestのlogが確認できる。
- 必要な送信元から到達し、不要な送信元からは到達しない。
- うまく動かない場合に、file、service、port、経路、logのどこから確認するかを説明できる。

練習の完成コマンド列をそのまま提出する課題にしません。学生へ配布する問題文、fixture、checker、教員記録を一組で確定します。
