# WEB-06 教員提供アプリとDBの接続

2026-10-23：現在の学生用課題は[詳細練習P5/P6](../../course/labs/docs/ja/practice.md)と[自力課題M5/M6](../../course/labs/docs/ja/missions.md)。提供appと固定registryへ照合した三言語HTML/PDFを[教材入口](../../course/labs/README.md)へ作成。以下は実装前の構想記録で、現状は[確認範囲](../../course/labs/VALIDATION.md)を優先する。

状態: 構成方針のみ。教員提供アプリ、EC2配置、Security Group、DB権限、手順、確認用課題、学生権限の実機検証は未実施。

## 目標

教員が用意した小さなアプリをWeb側に配置し、EC2上のDBへ接続します。学生はアプリのコードを書かず、起動設定、接続先、許可する通信、DBの権限、logを確認します。ブラウザからの操作がアプリを経てDBを利用し、結果が返るまでの流れを説明します。

## 制作時に必要な成果物

- 学習用アプリと架空データの配布元、使用版、起動・停止方法。
- EC2台数、VPC内の接続経路、Security Group、DBユーザーの最小権限。
- 手順付き練習と、異なる設定値・対象で行う課題。
- Web応答、アプリlog、DB側の記録による確認方法。
- 接続失敗をDNS、経路、service、認証、権限から切り分ける説明。
- 学生権限の新しいLearner Labでの通し検証記録。

アプリに認証情報を埋め込まない。実際の配布方法・環境変数・秘密の保管方法は、採用するLearner Labで使える機能を確認してから決めます。
