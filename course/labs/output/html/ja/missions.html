課題 M0〜M5

練習 P0〜P5 · 課題 M0〜M5

日本語 · Русский · O‘zbekcha

Pは詳しい操作例つきの練習です。Mは練習で学んだ設定を別の対象に自分で適用する課題です。サーバーを自分で設定してからブラウザで確認します。

練習 自力課題 テーマ 素点
P0 M0 サーバーの確認と接続 4
P1 M1 HTTPで静的ファイルを返す 8
P2 M2 内部DNSと通常の名前解決 13
P3 M3 PostgreSQLへの認証接続 9
P4 M4 教員アプリをWeb・DBへ接続する 13
P5 M5 最小権限と公開範囲 16

おすすめの順序:

P0 → M0 → P1 → M1 → P2 → M2 → P3 → M3 → P4 → P5 → M4 → M5

P4の前にM2、練習から本課題へ切り替える前にP5を終える。
