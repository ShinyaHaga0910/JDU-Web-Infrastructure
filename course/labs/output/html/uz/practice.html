Mashqlar P0–P6 · Topshiriqlar M0–M6

日本語 · Русский · O‘zbekcha

P — batafsil qadamli mashq. M — P da o‘rgangan sozlamani boshqa obyektga mustaqil qo‘llash. Avval serverlarni o‘zingiz sozlang, keyin brauzerda tekshiring.

Mashq Topshiriq Mavzu Xom ball
P0 M0 Shaxsiy muhit va buyruqlarni bajarish joyi O‘qituvchi e’lon qiladi
P1 M1 HTTP orqali statik faylni qaytarish 8
P2 M2 Ichki DNS va odatiy nom yechimi 13
P4 M4 PostgreSQL ga autentifikatsiya bilan ulanish 9
P5 M5 Berilgan app ni Web va DB bilan bog‘lash 13
P6 M6 Eng kam huquq va ochiq kirish chegarasi 16

Tavsiya etilgan tartib:

P0 → M0 → P1 → M1 → P2 → M2 → P4 → M4 → P5 → P6 → M5 → M6

P5 dan oldin M2 ni, practice → mission almashishdan oldin P6 ni tugating.
