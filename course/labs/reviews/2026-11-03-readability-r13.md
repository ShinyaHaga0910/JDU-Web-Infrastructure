## 修正内容

| 修正前の問題 | r1.3の対応 |
| --- | --- |
| GitHubのHTMLソース表示へ案内される | 入口をMarkdownに統一。HTMLは教材zip展開後のローカル閲覧用と明記 |
| 冒頭と末尾で配布期限が異なる | 共通の期限定義から2027年1月31日末（UZT）を生成 |
| 本文の採点方法がCLIのまま | 各P/Mからブラウザ確認・自動保存・成績閲覧へ案内 |
| 一冊が長く、目的の課題を探しにくい | 3言語×14課題を個別ページ化。一覧・共通準備・前後の課題へのリンクを追加 |
| 手順の説明が詰まって見える | 実行場所・目的・設定の意味・期待結果・失敗時のラベルを独立した段落へ整理 |
| 学生向け入口に制作履歴が混在する | 教師の事前準備・制作情報をTEACHER-NOTES.mdへ移動 |

P3/M3の停止前・停止中・再開後は同じブラウザ画面で記録します。P5/M5/P6/M6の既存アプリ管理者パスワードとRDP用パスワードを区別しました。
