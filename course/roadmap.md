# Webインフラストラクチャーの学習経路

| ID | 単位 | 完了したときに示すこと |
| --- | --- | --- |
| WEB-00 | [完成像](../modules/WEB-00-overview/README.md) | 役割、送信元、宛先、protocol、portの図と通信表 |
| WEB-01 | VPCと接続経路 | 管理・DNS・HTTP・DBの経路と拒否範囲 |
| WEB-02 | [HTTPとNginx](../modules/WEB-02-http/README.md) | 静的ページ、HTTP status、service、port、log |
| WEB-03 | 内部DNS | 問い合わせと回答、record、障害の切り分け |
| WEB-04 | Storage | 元root EBSのfile・権限、同じWebの停止/再開と保持（追加disk/backupは不要） |
| WEB-05 | PostgreSQL | DB、role、SCRAM、Webだけの接続、認証SELECT |
| WEB-06 | [教員提供アプリとDBの接続](../modules/WEB-06-app-integration/README.md) | Web側のアプリがDBへ接続し、結果をWebへ返す |
| WEB-07 | 公開範囲と権限 | 正常経路の許可と不要な経路の拒否 |
| WEB-08 | 観測と復旧 | 証拠に基づく原因特定と復旧確認 |
| WEB-09 | 完成確認と引き継ぎ | 他者が読める構成・停止・再開手順（本人実演の採点なし） |

これは教材単位の順序であり、授業回番号ではありません。一つの単位に複数回かけても、一回で複数の単位へ進んでも構いません。

## 2026-10-23 P/M教材の入口

[練習P0-P6 / 自力課題M0-M6](labs/README.md)を現在の課題教材とします。推奨順はP0→M0→P1→M1→P2→M2→P3→M3→P4→M4→P5→P6→M5→M6。P5もM2の正式DNSを使い、practice→mission切替前にP6で一時setupを終了します。Pは成績外、M0は0点、M1-M6は8/13/3/9/13/16＝62素点で、25点への換算は教師が別に行います。課題番号とWEB教材単位番号は別です。

2026-10-23時点では本人指示によりP/M課題教材を先行し、独立した教科書・投影資料は制作対象外としていました。旧WEB-02の初稿より新P1/M1を優先します。

## 2026-10-30 教科書の学習順序の整理

本人の新しい依頼により、OS・Linux教科書の形式を参考に、後半の教科書設計へ進みます。[授業の順序・段階ごとの必要知識・既存演習との対応](textbook-plan.md)を整理しました。章番号と授業回数は固定せず、現行P/Mの依存関係を維持します。

続いて、[全14章の章・節ごとの説明内容](textbook-outline.md)を具体化しました。各章に入口の問い、前提、説明順、図と観測、章末問題と解答の要点を置きます。本人指定により、学生が設定しないCookie等のアプリ内部機構は教科書本編の独立説明から外します。

単元の課題は満点まで完成させ、学生が課題画面の点数を見て次へ進みます。満点とは別のサービス再確認や教師承認は追加しません。第11〜12章のアプリ接続へは、第10章までのM1〜M4を順に満点で終えてから進みます。

[第1章の本文骨子・全体図・HTML/PDF](textbook/README.md)を作成しました。本人の最新依頼に従い、OS・Linux教材の形式を固定的に踏襲せず、教員が編集しやすい本文の土台とします。入口に章と各P/Mの対応を示します。

[第2章 AWS上のネットワークと通信経路](textbook/docs/ja/02-network-paths.md)の本文と4図、HTML/PDFを作成しました。第1章の編集方針を引き継ぎ、アドレス・ポート・SG・通信経路・ループバックを具体例で説明します。ルート表や採点条件の詳細は本文へ追加していません。
