# D08 初期環境の正式配布版

この配布物は、Web演習を始めるための5台構成、内部パッケージ配布、管理接続、個別採点登録を提供します。教師・別学生AWSアカウントで新規構築から停止・再開まで確認した署名済み本体を、そのまま収録しています。

**D08の初期環境配布が対象です。全課題・配点・教材の完成は含みません。** WEB-02のP1/M1は検証済みの課題候補です。表示される47/47や2/10は検査項目数で、科目の点数ではありません。D11・D12が終わるまで授業全体の準備完了とはしません。

`distribution-release.json`にClass・教師アカウント・配布版・有効期限を固定します。学生アカウントと匿名Lab IDは学生ごとの受け渡し時に照合します。別Classでは、そのClassの教師と受入済み本体から別の配布版を作ります。

`core/`は受入済み候補の原本です。中のCANDIDATE表記は当時の履歴として保持し、この配布版の署名とACCEPTANCE.jsonで初期環境の配布への昇格を記録します。内側の原本を書き換えず、既存環境のstateや認証を引き継ぎます。

外側archiveの署名を展開前に確認し、展開後は全fileの署名・hash・期限を再確認します。完全な署名鍵fingerprintは、配布物とは独立した教師の案内で確認します。

既存の学生環境はその学生の元のtoolsとstateを使い続けます。今回の配布版の導入のために5台を作り直したり、鍵・採点認証を発行し直したりする必要はありません。
